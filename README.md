## 🐟 About the Name

**"ThreeFish" is a pun.** My bio quotes Dong Yu (董遇), a 3rd-century scholar, on his "Three Surpluses" (三余) philosophy of study<sup>[[1]](#ref1)</sup>:

> 冬者岁之余，夜者日之余，阴雨者时之余。
> _Winter is the year's surplus; night is the day's surplus; a rainy day is time's surplus._

His point: don't wait for spare time — reclaim the surplus hours everyone else lets go to waste. In Mandarin, "three surpluses" (三余, _sān yú_) is a near-homophone of "three fish" (三鱼, _sān yú_) — so **ThreeFish** is a whimsical transliteration of an 1,800-year-old study philosophy, not a random brand name.

I apply the same instinct one layer up, as an engineering discipline: **entropy reduction (熵减)**. Left alone, information systems drift toward noise and forgetting, the same way unclaimed time drifts toward waste. My flagship project, [negentropy](https://github.com/ThreeFish-AI/negentropy), borrows its name directly from Schrödinger's negative entropy<sup>[[2]](#ref2)</sup> — order sustained by continuously importing more of it. Reclaiming surplus time and reclaiming order from information chaos are, to me, the same move at two different scales.

By day I build agent infrastructure that has to survive production traffic; the open source below happens in exactly those surplus hours — nights, weekends, rainy days. And this account compounds the same way: 129 contributions in 2020, the year I came back → 676 (2022) → 1,179 (2024) → 3,193 (2025) → 9,218 and counting in 2026. Entropy reduction, applied to my own time.
